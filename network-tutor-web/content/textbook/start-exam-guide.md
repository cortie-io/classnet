공부를 시작하기 전에 시험이 어떻게 생겼는지부터 알아 두면 훨씬 덜 막막해요. 이 단원에서는 네트워크관리사 2급 필기시험의 구성과 네 과목이 각각 무엇을 다루는지 살펴보고, classnet의 교재와 기능을 어떤 순서로 쓰면 좋은지 정리해요.

> [!GOAL]
> - 네트워크관리사 2급 필기시험의 문항 수, 시간, 합격 기준을 말할 수 있어요.
> - 네 과목이 각각 어떤 내용을 다루는지 큰 그림으로 설명할 수 있어요.
> - classnet의 학습 기능을 언제 어떻게 쓸지 알고, 나만의 공부 계획을 세울 수 있어요.

## 네트워크관리사 2급은 어떤 시험인가요

네트워크관리사는 네트워크를 설치하고 운영하는 데 필요한 지식과 기술을 확인하는 자격이에요. 시행처는 **한국정보통신자격협회(ICQA)**예요. 2급 시험은 **필기**와 **실기**로 나뉘고, 필기에 합격해야 실기를 볼 수 있어요.

이 교재가 목표로 하는 것은 **필기시험**이에요. 필기에서는 이론 지식을 객관식으로 묻고, 실기에서는 실제 설정과 작업 능력을 확인해요. 필기에서 배운 개념(IP 주소, 명령어, 장비의 역할 등)은 실기의 바탕이 되기 때문에, 필기 공부를 탄탄히 해 두면 실기 준비도 한결 수월해요.

> [!WARNING]
> 응시료, 시험 일정, 접수 방법, 세부 합격 기준처럼 바뀔 수 있는 정보는 이 교재에 적지 않았어요. 접수하기 전에 반드시 **시행처 공지**를 직접 확인하세요.

## 필기시험의 구성

### 시험 형식과 합격 기준

| 항목 | 내용 |
|---|---|
| 문항 형식 | 객관식 4지선다 |
| 문항 수 | 50문항 |
| 시험 시간 | 50분 |
| 합격 기준 | 100점 만점에 60점 이상 |

50문항을 50분 안에 풀어야 하니 한 문제에 쓸 수 있는 시간은 평균 1분이에요. 대부분은 개념을 알면 바로 답이 보이는 문제이고, 서브넷 계산처럼 손으로 풀어야 하는 문제는 일부예요. 그래서 **암기형 문제는 빠르게, 계산 문제는 정확하게** 푸는 연습이 필요해요.

### 네 과목이 다루는 내용

필기시험은 다음 네 과목에서 출제돼요.

| 과목 | 무엇을 배우나요 | 이 교재의 첫 단원 |
|---|---|---|
| 1과목 네트워크 일반 | 신호와 전송, 다중화, 전송 매체, 오류 제어, OSI 7계층, LAN·WAN 기술 | [데이터 통신의 기본](/textbook/net-data-communication) |
| 2과목 TCP/IP | IP 주소와 서브네팅, TCP·UDP, 포트 번호, DNS·DHCP, 라우팅, IPv6, 보안 기초 | [TCP/IP 모델과 캡슐화](/textbook/tcpip-model) |
| 3과목 NOS(네트워크 운영체제) | Windows Server의 역할과 서비스, 리눅스 명령어와 권한, 서버 설정 | [운영체제와 네트워크 운영체제](/textbook/nos-os-basics) |
| 4과목 네트워크 운용기기 | 허브·스위치·라우터, VLAN, 보안 장비, 서버·스토리지, 케이블링 | [1·2계층 장비](/textbook/dev-l1-l2-devices) |

시행처는 과목마다 5~18문항 범위에서 낸다고만 밝히고 있어서 정확한 배분은 회차마다 조금씩 달라질 수 있어요. 지난 기출문제를 보면 **NOS가 가장 많이(18문항 안팎), 네트워크 운용기기가 가장 적게(5문항 안팎)** 나오고, 나머지 두 과목이 그 사이를 나눠 가져요. 문항 수가 많은 NOS와, 계산 문제가 있는 TCP/IP에 공부 시간을 넉넉히 배정하는 편이 좋아요.

> [!NOTE]
> 과목 순서는 시행처 안내를 따라 네트워크 일반을 1과목으로 적었어요. 기출문제지나 문제 풀이 사이트에 따라 TCP/IP를 먼저 싣는 곳도 있으니, 과목은 번호보다 이름으로 기억해 두세요.

> [!TIP]
> 과목 이름이 낯설어도 걱정하지 마세요. 한 줄로 줄이면 1과목은 "통신이 어떻게 이루어지나", 2과목은 "인터넷의 약속(프로토콜)", 3과목은 "서버 컴퓨터 다루기", 4과목은 "네트워크 장비 다루기"예요.

### 문제 유형 미리 보기

과목과 상관없이 자주 나오는 문제 유형은 몇 가지로 정리돼요.

- **정의 고르기**: "다음 설명에 해당하는 것은?" 처럼 개념의 설명을 주고 이름을 고르는 문제
- **옳은 것·틀린 것 고르기**: 보기 네 개 중 하나만 맞거나 하나만 틀린 문제. 비슷한 개념을 섞어 함정을 만들어요.
- **계산 문제**: 서브넷 마스크, 호스트 수, 전송 속도처럼 숫자를 구하는 문제
- **명령어·설정 문제**: Windows·리눅스 명령어나 라우터 명령의 기능을 묻는 문제
- **포트 번호·계층 짝짓기**: 프로토콜과 포트 번호, 장비와 OSI 계층을 연결하는 문제

## classnet으로 공부하는 방법

classnet에는 읽기, 풀기, 복습하기에 맞춘 기능이 나뉘어 있어요. 각각 언제 쓰면 좋은지 알아 두세요.

### 교재

네트워크를 처음 공부한다면 여기서 시작하세요. 교재 단원을 **정해진 순서대로** 따라가는 학습 경로예요.

1. 단원을 처음부터 끝까지 읽어요. 단원 끝의 "핵심 정리"와 "스스로 확인하기"까지 꼭 봐요.
2. **단원 확인 문제**를 풀어요. 방금 배운 내용이 문제로 어떻게 나오는지 확인하는 단계예요.
3. 확인이 끝나면 **다음 단원**으로 넘어가요.

앞 단원의 개념을 뒤 단원에서 계속 쓰기 때문에, 처음 한 바퀴는 건너뛰지 않고 순서대로 가는 것을 추천해요.

### 교재

학습 경로와 같은 단원을 **목차에서 골라 언제든 찾아 읽는** 곳이에요. 문제를 풀다가 개념이 흐릿할 때, 시험 직전에 특정 단원만 다시 볼 때 쓰면 좋아요.

### AI 튜터 채팅

모르는 것이 생기면 언제든 AI 튜터에게 물어보세요. 예를 들면 이렇게 쓸 수 있어요.

- 개념 질문: "반이중과 전이중 차이를 쉬운 예로 설명해 줘"
- 풀이 질문: "이 서브넷 문제를 단계별로 풀어 줘"
- 문제 요청: "서브넷 문제 3개 줘", "리눅스 권한 문제 5개 내 줘"

교재를 읽다가 막힌 문장을 그대로 붙여 넣고 "이게 무슨 뜻이야?"라고 물어도 돼요. 이해가 될 때까지 꼬리 질문을 이어 가는 것이 채팅의 가장 큰 장점이에요.

### 문제 풀기 기능

| 기능 | 이렇게 써요 |
|---|---|
| 과목별 문제 연습 | 과목과 문항 수를 골라 짧게 풀어요. 단원을 마친 뒤 그 과목만 집중해서 연습할 때 좋아요. |
| 모의고사 | 실제 필기시험과 같은 50문항·50분으로 시간을 재며 풀어요. 실전 감각과 시간 배분을 익혀요. |
| 기출문제 | 실제로 출제됐던 회차를 골라 원래 순서대로 풀어요. 시험의 출제 경향을 몸으로 익혀요. |

### 복습 기능

| 기능 | 이렇게 써요 |
|---|---|
| 오답노트 | 틀린 문제가 자동으로 모여요. 해설을 다시 보고, 왜 틀렸는지 AI 튜터에게 물어보며 약점을 채워요. |
| 플래시카드 | 카드를 뒤집으며 용어의 정의를 외워요. 포트 번호, 명령어, 약어처럼 외울 것이 많은 부분에 좋아요. |
| 나의 학습 리포트 | 과목·주제별 정답률을 보고 약한 부분을 찾아요. 다음에 무엇을 공부할지 정하는 기준이 돼요. |

## 추천 공부 순서

처음 공부하는 학생에게 권하는 순서예요. 기간은 사람마다 다르니 단계를 기준으로 계획을 세우세요.

| 단계 | 할 일 | 포인트 |
|---|---|---|
| 1단계 | 시작하기 3단원 | 진법 변환과 네트워크의 큰 그림을 먼저 잡아요. 특히 2진수는 서브네팅의 바탕이에요. |
| 2단계 | 1과목 네트워크 일반 | 용어가 가장 많이 처음 나오는 과목이에요. OSI 7계층은 모든 과목에 다시 나오니 확실히 익혀요. |
| 3단계 | 2과목 TCP/IP | 계산 문제가 나오는 과목이에요. 서브네팅 계산은 예제를 손으로 여러 번 풀어 봐요. |
| 4단계 | 3과목 NOS | Windows Server와 리눅스 명령어가 많아요. 명령어는 기능과 함께 짝지어 외워요. |
| 5단계 | 4과목 네트워크 운용기기 | 앞에서 배운 계층 지식으로 장비를 정리하면 빠르게 끝낼 수 있어요. |
| 6단계 | 기출·모의고사 반복 | 기출 회차를 풀고, 틀린 문제는 오답노트와 교재로 돌아가 다시 확인해요. 모의고사로 시간 배분을 연습해요. |

> [!NOTE]
> 하루에 1~2단원씩 꾸준히 읽으면 교재 전체를 한 바퀴 도는 데 대략 한두 달이 걸려요. 이 기간은 예시일 뿐이에요. 빨리 끝내는 것보다 매일 조금씩 이어 가는 것이 더 중요해요.

### 공부할 때 기억할 것

- **이해 먼저, 암기는 나중에.** 왜 그렇게 동작하는지 알면 외울 양이 줄어들어요. 예를 들어 "스위치는 MAC 주소를 보고 판단한다"를 이해하면 스위치가 2계층 장비라는 것은 따로 외우지 않아도 돼요.
- **계산 문제는 손으로.** 진법 변환과 서브넷 계산은 눈으로 읽기만 해서는 늘지 않아요. 종이에 직접 풀어 보세요.
- **틀린 문제가 가장 좋은 교재예요.** 오답노트에 쌓인 문제를 다시 풀고, 관련 단원을 다시 읽는 습관을 들이세요.
- **기출은 외우지 말고 이해하기.** 같은 개념이 다른 문장으로 나올 수 있어요. 정답 번호가 아니라 정답인 이유를 기억하세요.
- **시험 직전에는 핵심 정리만.** 각 단원의 "핵심 정리"를 모아 훑어보면 짧은 시간에 전체를 복습할 수 있어요.

> [!EXAM]
> 필기시험은 하나의 개념을 여러 과목에서 다시 물어요. 예를 들어 포트 번호는 2과목에서, 같은 서비스를 서버에 설정하는 방법은 3과목에서, 그 서비스를 보호하는 방화벽은 4과목에서 나와요. 과목을 따로따로 외우기보다 서로 연결해 두면 점수가 안정돼요.

## 핵심 정리

- 네트워크관리사 2급의 시행처는 한국정보통신자격협회(ICQA)이고, 필기에 합격하면 실기를 볼 수 있어요.
- 필기는 객관식 4지선다 50문항, 50분이며, 100점 만점에 60점 이상이면 합격이에요.
- 과목은 네트워크 일반, TCP/IP, NOS(네트워크 운영체제), 네트워크 운용기기 네 가지예요.
- 기출을 보면 NOS가 가장 많이(18문항 안팎), 네트워크 운용기기가 가장 적게(5문항 안팎) 나와요.
- 응시료·일정·세부 기준은 바뀔 수 있으니 시행처 공지를 직접 확인해요.
- 처음이라면 "교재"로 단원을 순서대로 읽고, 단원 확인 문제를 푼 뒤 다음 단원으로 넘어가요.
- 모르는 개념은 AI 튜터에게 묻고, 과목별 문제 연습·기출문제·모의고사로 실력을 확인해요.
- 틀린 문제는 오답노트로, 외울 것은 플래시카드로, 약한 주제는 나의 학습 리포트로 관리해요.
