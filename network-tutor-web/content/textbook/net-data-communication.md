1과목의 첫 단원이에요. 데이터가 한 장치에서 다른 장치로 건너가려면 어떤 장비들이 필요하고, 데이터를 어떤 방향으로, 몇 줄로, 어떤 박자에 맞춰 보내는지를 정리해요. 여기서 나오는 단방향·반이중·전이중, 직렬·병렬, 동기·비동기는 시험에서 정의와 예를 짝지어 자주 묻는 기본 개념이에요.

> [!GOAL]
> - 데이터 통신 시스템을 이루는 요소와 DTE·DCE의 역할을 설명할 수 있어요.
> - 단방향·반이중·전이중 방식을 구분하고 알맞은 예를 고를 수 있어요.
> - 직렬·병렬 전송과 비동기·동기 전송의 특징을 비교하고, 비동기 전송의 효율을 계산할 수 있어요.
> - 베이스밴드 전송과 브로드밴드 전송의 차이를 말할 수 있어요.

## 데이터 통신이란

**데이터 통신(Data Communication)**은 컴퓨터처럼 데이터를 처리하는 기계들이 전송 매체를 통해 데이터를 주고받는 것이에요. 사람끼리 목소리를 주고받는 전화와 달리, 0과 1로 된 데이터를 정확하게 전달하는 것이 목적이에요. 데이터를 보내는 기술(통신)에 받은 데이터를 처리하는 기술(컴퓨터)까지 합쳐 넓게 부를 때는 **정보 통신**이라는 말도 써요.

## 데이터 통신 시스템의 구성

### 통신에 꼭 필요한 다섯 가지

어떤 통신이든 다음 다섯 가지가 있어야 성립해요.

| 요소 | 뜻 | 예 |
|---|---|---|
| 메시지(Message) | 전달하려는 데이터 | 문서, 사진, 음성 |
| 송신자(Sender) | 데이터를 보내는 장치 | 민수의 컴퓨터 |
| 수신자(Receiver) | 데이터를 받는 장치 | 학교 서버 |
| 전송 매체(Medium) | 데이터가 지나가는 길 | 케이블, 전파 |
| 프로토콜(Protocol) | 양쪽이 지키는 통신 규칙 | 데이터 형식, 순서 |

### 데이터 전송계와 데이터 처리계

시험에서는 데이터 통신 시스템을 크게 두 부분으로 나눠서 물어요.

- **데이터 전송계**: 데이터를 실어 나르는 부분이에요. 단말 장치, 신호 변환 장치, 통신 회선, 통신 제어 장치가 여기에 속해요.
- **데이터 처리계**: 받은 데이터를 처리하는 컴퓨터 쪽이에요. 중앙 처리 장치와 주변 장치가 여기에 속해요.

```text
단말 장치(DTE) → 신호 변환 장치(DCE) → 통신 회선
→ 신호 변환 장치(DCE) → 통신 제어 장치(CCU) → 컴퓨터

데이터 전송계: 단말 장치부터 통신 제어 장치까지
데이터 처리계: 컴퓨터
```

### 단말 장치 — DTE

**DTE(Data Terminal Equipment, 데이터 단말 장치)**는 데이터가 처음 만들어지거나 마지막에 도착하는 장치예요. 사용자가 직접 쓰는 컴퓨터, 단말기가 여기에 해당해요. 데이터를 입력·출력하고, 통신 회선과 연결되는 출발점이자 도착점이에요.

### 신호 변환 장치 — DCE

**DCE(Data Circuit-terminating Equipment, 데이터 회선 종단 장치)**는 DTE가 만든 신호를 통신 회선에 알맞은 신호로 바꾸고, 반대로 회선에서 온 신호를 DTE가 이해하는 신호로 되돌려요. 회선의 양 끝에 하나씩 있어요.

| 장치 | 바꾸는 방향 | 쓰는 곳 |
|---|---|---|
| 모뎀(MODEM) | 디지털 신호 ↔ 아날로그 신호 | 아날로그 회선(전화선 등) |
| DSU(Digital Service Unit) | 디지털 신호 ↔ 디지털 회선용 신호 | 디지털 전용 회선 |
| 코덱(CODEC) | 아날로그 신호(음성·영상) ↔ 디지털 신호 | 디지털 회선으로 음성·영상 전송 |

모뎀은 변조기(MOdulator)와 복조기(DEModulator)를 합친 이름이에요. 변조는 다음 단원 [신호와 변조](/textbook/net-signal-modulation)에서 자세히 배워요.

> [!WARNING]
> **모뎀과 코덱의 방향을 헷갈리지 마세요.** 모뎀은 디지털 데이터를 아날로그 회선에 싣기 위한 장치이고, 코덱은 아날로그 음성·영상을 디지털로 바꾸기 위한 장치예요. 서로 반대 방향이라고 기억하면 돼요.

DTE와 DCE 사이를 잇는 규격(인터페이스)으로는 **RS-232C**가 대표적이에요. 미국 EIA가 정한 직렬 인터페이스 규격이고, 국제 표준인 ITU-T의 V.24 등이 이에 대응해요.

### 통신 제어 장치 — CCU

**통신 제어 장치(CCU, Communication Control Unit)**는 데이터 전송계와 컴퓨터 사이에서 통신과 관련된 잡무를 맡아요. 컴퓨터가 계산에만 집중할 수 있도록 돕는 비서라고 생각하면 돼요.

- 전송 제어: 여러 회선의 데이터 송수신을 관리해요.
- 오류 제어: 전송 중 생긴 오류를 찾아내고 바로잡아요.
- 동기 제어와 흐름 제어: 송신과 수신의 속도와 박자를 맞춰요.
- 버퍼링: 회선 속도와 컴퓨터 처리 속도의 차이를 임시 저장소로 메워요.

> [!NOTE]
> 대형 컴퓨터 앞에 따로 두고 통신 처리를 대신 맡기는 장치를 **전처리기(FEP, Front-End Processor)**라고 해요. 통신 제어 장치의 역할을 하는 전용 컴퓨터라고 보면 돼요.

## 전송 방향에 따른 분류

데이터가 어느 방향으로 흐를 수 있느냐에 따라 세 가지로 나눠요.

### 단방향 통신

**단방향(Simplex)** 통신은 한쪽은 보내기만, 다른 쪽은 받기만 하는 방식이에요. 라디오와 TV 방송이 대표적이에요. 방송국은 내보내기만 하고, 시청자의 TV는 받기만 해요.

### 반이중 통신

**반이중(Half Duplex)** 통신은 양쪽 모두 보낼 수 있지만 **동시에는 한쪽만** 보낼 수 있는 방식이에요. 무전기가 대표적이에요. 버튼을 누르고 말하는 동안에는 상대방 말을 들을 수 없고, 말이 끝나면 "이상"이라고 하며 차례를 넘겨요. 보내는 방향을 바꿀 때마다 전환 시간이 필요해서 전송 효율이 떨어져요. 허브로 연결된 옛 이더넷도 반이중으로 동작했어요.

### 전이중 통신

**전이중(Full Duplex)** 통신은 양쪽이 **동시에** 보내고 받을 수 있는 방식이에요. 전화 통화가 대표적이에요. 상대방이 말하는 도중에도 내가 끼어들 수 있어요. 오늘날 스위치에 연결된 유선 LAN도 대부분 전이중으로 동작해요.

| 방식 | 방향 | 동시 송수신 | 예 | 효율 |
|---|---|---|---|---|
| 단방향(Simplex) | 한쪽으로만 | 불가 | 라디오, TV 방송 | 낮음 |
| 반이중(Half Duplex) | 양쪽 | 불가(번갈아) | 무전기 | 중간 |
| 전이중(Full Duplex) | 양쪽 | 가능 | 전화 | 높음 |

> [!TIP]
> 한 차선 일방통행 도로는 단방향, 공사 구간에서 신호수가 번갈아 한쪽씩 보내 주는 1차선 도로는 반이중, 왕복 2차선 도로는 전이중이에요.

> [!NOTE]
> 옛 아날로그 데이터 회선에서는 반이중에 2선식 회선을, 전이중에 4선식 회선(보내는 쌍과 받는 쌍을 따로)을 주로 썼어요. 그래서 "전이중은 4선식"이라는 짝으로 묻기도 해요.

## 직렬 전송과 병렬 전송

한 번에 몇 비트씩 보내느냐에 따른 구분이에요.

### 직렬 전송

**직렬 전송(Serial Transmission)**은 데이터를 **한 비트씩 차례로** 한 줄의 통신로로 보내는 방식이에요. 1바이트를 보내려면 8번에 나눠 보내요. 선이 적게 들어 비용이 싸고 먼 거리에 알맞아서, 컴퓨터 사이의 통신은 대부분 직렬 전송이에요.

### 병렬 전송

**병렬 전송(Parallel Transmission)**은 여러 비트를 **여러 줄의 통신로로 동시에** 보내는 방식이에요. 예를 들어 선 8개로 1바이트를 한꺼번에 보내요. 같은 속도의 선이라면 한 번에 많이 보내니 빠르지만, 선이 많아 비용이 크고, 거리가 길어지면 각 선의 비트가 도착하는 시간이 조금씩 어긋나는 **스큐(Skew)** 문제가 생겨요. 그래서 컴퓨터 내부나 컴퓨터와 가까운 주변 장치 사이처럼 **짧은 거리**에서 써요.

```text
직렬:  A ==[1][0][1][1][0][0][1][0]==> B   (한 줄로 차례로)

병렬:  A ==[1]==> B
       A ==[0]==> B
       A ==[1]==> B    (여러 줄로 동시에)
       ...
```

| 구분 | 직렬 전송 | 병렬 전송 |
|---|---|---|
| 한 번에 보내는 비트 | 1비트 | 여러 비트(예: 8비트) |
| 통신로(선) 수 | 적음 | 많음 |
| 비용 | 낮음 | 높음 |
| 알맞은 거리 | 원거리 | 근거리 |
| 주 사용처 | 컴퓨터 간 통신, 네트워크 | 컴퓨터 내부, 가까운 주변 장치 |

> [!NOTE]
> 요즘 컴퓨터의 고속 연결(USB, SATA, PCIe 등)은 대부분 직렬 방식이에요. 속도를 아주 높이면 병렬 선들 사이의 스큐와 간섭이 더 큰 문제가 되기 때문이에요. 시험에서는 "병렬은 근거리·고속, 직렬은 원거리·저비용"이라는 전통적인 비교로 물어요.

## 비동기 전송과 동기 전송

직렬로 비트를 보내면 받는 쪽은 "어디서부터 한 글자가 시작되는지", "비트 하나가 언제 끝나는지"를 알아야 해요. 송신 측과 수신 측이 이 박자를 맞추는 것을 **동기화(Synchronization)**라고 하고, 방법에 따라 비동기식과 동기식으로 나눠요.

### 비동기식 전송

**비동기식 전송(Asynchronous Transmission)**은 **한 문자 단위로** 박자를 맞추는 방식이에요. 각 문자 앞에 **스타트 비트(Start Bit)**, 뒤에 **스톱 비트(Stop Bit)**를 붙여서 문자의 시작과 끝을 알려요. 그래서 **조보식(Start-Stop) 전송**이라고도 해요.

- 보낼 것이 없을 때 회선은 1 상태로 쉬고 있어요(휴지 상태).
- 스타트 비트(0) 1개가 오면 수신 측이 "이제 한 문자가 시작된다"고 알아채요.
- 문자 비트(보통 7~8비트)와, 필요하면 오류 확인용 패리티 비트가 뒤따라요.
- 스톱 비트(1) 1~2개로 문자가 끝났음을 알려요.
- 문자와 문자 사이의 쉬는 시간은 일정하지 않아도 돼요.

```text
[휴지 1111] [스타트 0] [데이터 10110010] [스톱 1] [휴지 1111]
```

구조가 간단하고 장비가 싸지만, 문자마다 스타트·스톱 비트가 붙어서 **효율이 낮고** 고속 전송에는 알맞지 않아요.

**효율 계산 예제** 데이터 8비트, 스타트 비트 1개, 스톱 비트 1개, 패리티 없음일 때 전송 효율은?

1. 한 문자에 실제로 보내는 비트: 1 + 8 + 1 = 10비트
2. 그중 진짜 데이터: 8비트
3. 효율 = 8 ÷ 10 = **80%**

여기에 패리티 비트 1개를 더하면 8 ÷ 11 ≈ 72.7%로 더 떨어져요.

### 동기식 전송

**동기식 전송(Synchronous Transmission)**은 문자를 하나씩 보내지 않고 **여러 문자를 블록(프레임)으로 묶어서** 한꺼번에 보내는 방식이에요. 송신 측과 수신 측이 같은 클럭(박자)에 맞춰 움직이고, 블록 앞뒤에 동기를 맞추기 위한 신호만 붙여요. 문자마다 부가 비트가 붙지 않으니 효율이 높고 **고속 대량 전송**에 알맞아요. 대신 블록을 모아 둘 **버퍼**가 필요하고 장비가 복잡해요.

동기식은 블록의 시작을 알리는 방법에 따라 두 가지로 나눠요.

| 방식 | 블록 시작 표시 | 대표 프로토콜 |
|---|---|---|
| 문자 동기 방식(문자 위주) | SYN 같은 특별한 동기 문자 | BSC |
| 비트 동기 방식(비트 위주) | 플래그 비트열 01111110 | HDLC, SDLC |

비트 동기 방식은 데이터를 문자 단위로 해석하지 않아도 되므로 어떤 형식의 데이터든 보낼 수 있어요. HDLC는 [WAN 기술](/textbook/net-wan-technologies)에서 다시 만나요.

### 한눈에 비교하기

| 구분 | 비동기식 | 동기식 |
|---|---|---|
| 전송 단위 | 문자 | 블록(프레임) |
| 동기 방법 | 문자마다 스타트·스톱 비트 | 블록 앞뒤 동기 문자·플래그, 공통 클럭 |
| 문자 사이 간격 | 불규칙해도 됨 | 쉬지 않고 연속 |
| 효율 | 낮음 | 높음 |
| 속도 | 저속 | 고속 |
| 버퍼 | 거의 필요 없음 | 필요 |
| 장비 | 간단·저렴 | 복잡·비쌈 |

> [!NOTE]
> 두 방식을 섞은 **혼합형 동기식** 전송도 있어요. 문자마다 스타트·스톱 비트를 붙이는 점은 비동기식과 같지만, 송신 측과 수신 측이 동기 상태를 유지해서 비동기식보다 빠르게 보낼 수 있어요.

> [!EXAM]
> "스타트 비트와 스톱 비트를 사용한다", "문자 단위", "저속", "조보식"은 **비동기식**의 단서예요. "블록 단위", "SYN 문자", "플래그", "고속", "버퍼 필요"는 **동기식**의 단서예요. 보기에 단서를 일부러 바꿔 끼워 넣는 함정이 많으니 짝을 정확히 기억하세요.

## 베이스밴드 전송과 브로드밴드 전송

신호를 변조해서 보내느냐에 따라서도 나눠요.

- **베이스밴드 전송(Baseband, 기저대역 전송)**: 디지털 신호를 **변조하지 않고** 전압 펄스 그대로(회선 부호화만 거쳐) 보내는 방식이에요. 한 번에 한 신호가 매체의 대역을 모두 차지해요. 장비가 간단해서 LAN처럼 **가까운 거리**에서 써요. 이더넷 규격 이름 10BASE-T의 "BASE"가 바로 베이스밴드라는 뜻이에요.
- **브로드밴드 전송(Broadband, 광대역 전송)**: 신호를 반송파에 **변조해서** 보내는 방식이에요. 매체의 넓은 대역을 여러 주파수 구간으로 나눠 **여러 채널을 동시에** 보낼 수 있어요. 케이블 TV가 대표적이에요.

| 구분 | 베이스밴드 | 브로드밴드 |
|---|---|---|
| 신호 | 디지털 신호 그대로 | 변조된 신호 |
| 채널 | 한 번에 하나 | 주파수를 나눠 여러 개 |
| 거리 | 근거리 | 상대적으로 원거리 |
| 예 | 이더넷 LAN | 케이블 TV |

회선 부호화는 [신호와 변조](/textbook/net-signal-modulation)에서, 주파수를 나눠 여러 채널을 보내는 방법은 [다중화와 다중 접속](/textbook/net-multiplexing)에서 배워요.

> [!NOTE]
> 일상에서 "브로드밴드"는 그냥 "초고속 인터넷"이라는 뜻으로도 쓰여요. 시험에서는 위의 기술적인 뜻(변조와 여러 채널)으로 물어요.

## 핵심 정리

- 통신의 다섯 요소는 메시지, 송신자, 수신자, 전송 매체, 프로토콜이에요.
- 데이터 통신 시스템은 데이터 전송계(단말 장치, 신호 변환 장치, 통신 회선, 통신 제어 장치)와 데이터 처리계(컴퓨터)로 나눠요.
- DTE는 데이터 단말 장치, DCE는 신호를 회선에 맞게 바꾸는 장치예요. 모뎀은 디지털 ↔ 아날로그, DSU는 디지털 ↔ 디지털, 코덱은 아날로그 ↔ 디지털이에요.
- 단방향은 방송, 반이중은 무전기, 전이중은 전화가 대표 예예요.
- 직렬은 한 줄로 한 비트씩(원거리·저비용), 병렬은 여러 줄로 동시에(근거리·고속)예요.
- 비동기식은 문자 단위로 스타트·스톱 비트를 붙이고(조보식), 동기식은 블록 단위로 묶어 고속 전송해요.
- 비동기 전송 효율 = 데이터 비트 ÷ (스타트 + 데이터 + 패리티 + 스톱 비트)예요.
- 동기식은 문자 동기(SYN, BSC)와 비트 동기(플래그 01111110, HDLC)로 나눠요.
- 베이스밴드는 변조 없이 디지털 신호 그대로(이더넷), 브로드밴드는 변조해서 여러 채널을 보내요(케이블 TV).

## 스스로 확인하기

**1.** 양쪽 모두 데이터를 보낼 수 있지만, 한순간에는 한쪽만 보낼 수 있는 통신 방식은?

① 단방향 ② 반이중 ③ 전이중 ④ 다중화

> [!ANSWER]
> 정답: ②
> 무전기처럼 번갈아 보내는 방식이 반이중이에요. 전이중은 동시에 양방향, 단방향은 한쪽으로만 보내요.

**2.** 비동기식 전송에 대한 설명으로 옳지 않은 것은?

① 문자 단위로 전송한다.
② 각 문자 앞뒤에 스타트 비트와 스톱 비트를 붙인다.
③ 플래그로 블록의 경계를 표시하여 대량의 데이터를 고속으로 보내는 데 알맞다.
④ 문자와 문자 사이의 쉬는 시간이 일정하지 않아도 된다.

> [!ANSWER]
> 정답: ③
> 플래그로 블록 경계를 표시하고 고속 대량 전송에 쓰는 것은 동기식(비트 동기 방식)의 특징이에요.

**3.** 비동기식 전송에서 데이터 8비트에 스타트 비트 1개와 스톱 비트 1개를 붙이고 패리티 비트는 쓰지 않을 때, 전송 효율은?

① 70% ② 80% ③ 88.9% ④ 100%

> [!ANSWER]
> 정답: ②
> 한 문자에 10비트를 보내고 그중 데이터가 8비트이므로 8 ÷ 10 = 80%예요.

**4.** 컴퓨터의 디지털 데이터를 아날로그 전화 회선으로 보낼 수 있도록 신호를 바꿔 주는 장치는?

① 모뎀 ② DSU ③ 코덱 ④ 통신 제어 장치

> [!ANSWER]
> 정답: ①
> 모뎀은 디지털 신호를 아날로그 신호로 변조하고 다시 복조해요. DSU는 디지털 회선용, 코덱은 아날로그 음성·영상을 디지털로 바꾸는 장치예요.

**5.** 베이스밴드 전송에 대한 설명으로 옳은 것은?

① 신호를 여러 주파수 대역으로 나눠 여러 채널을 동시에 보낸다.
② 디지털 신호를 변조하지 않고 그대로 보낸다.
③ 케이블 TV 방송이 대표적인 예이다.
④ 반드시 아날로그 신호로 바꾼 뒤 전송한다.

> [!ANSWER]
> 정답: ②
> 베이스밴드는 변조 없이 디지털 신호를 그대로 보내는 방식이고 이더넷 LAN이 대표 예예요. ①, ③은 브로드밴드 전송의 설명이에요.
